# BMI Calculator

A simple web-based BMI calculator built with HTML, CSS, and JavaScript. The project allows users to enter their age, gender, height, and weight, then calculates Body Mass Index (BMI) and shows the corresponding health category with a basic suggestion.

## Features

- Calculates BMI based on height and weight input
- Displays BMI category: Underweight, Healthy, Overweight, or Obese
- Shows a short health suggestion based on the result
- Responsive layout for desktop and mobile screens

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

Open `index.html` in any modern web browser. No installation or additional setup is required.

## Project Structure

- `index.html` - Main page structure
- `style.css` - Styling and responsive layout
- `script.js` - BMI calculation logic and result handling
